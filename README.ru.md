# Marketplace

Серверная часть маркетплейса на NestJS: пользователи, каталог товаров, склад, корзина и оформление заказов.

## Возможности

- Регистрация и вход, роли пользователей, JWT-токены и обновление сессии.
- Просмотр, поиск и управление товарами и категориями; продавцы могут добавлять и редактировать товары.
- Просмотр и изменение остатков, резервирование товаров на время оформления заказа.
- Корзина, просмотр заказов и их статусов, отмена заказа.
- Асинхронное оформление заказа: резервирование остатков, оплата и подтверждение; при сбоях процесс повторяется или компенсируется.
- Уведомления: хранение, получение через HTTP и доставка в реальном времени через Socket.IO.

## Как устроена система

REST API принимает запросы через API Gateway. Шесть доменных сервисов отвечают за пользователей, каталог, склад, заказы, платежи и уведомления. Для синхронного взаимодействия используется gRPC, для фоновых событий — Kafka. Сервисы владеют отдельными базами PostgreSQL; Redis используется для кэша, MinIO — для файлов.

Платёжный провайдер сейчас имитируется. Согласование оформления заказа выполняется в сервисе заказов; подробности и ограничения описаны в [схеме процессов](doc/README.ru.md).
